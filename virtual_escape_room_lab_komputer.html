PETUNJUK RUMUS INVERS FUNGSI $f^{-1}(x)$

1. Invers Fungsi Linear:

Jika $f(x) = ax + b$, maka rumus inversnya adalah:

$f^{-1}(x) = \frac{x - b}{a}$

2. Invers Fungsi Rasional (Pecahan):

Jika $f(x) = \frac{ax + b}{cx + d}$, maka rumus inversnya adalah:

$f^{-1}(x) = \frac{-dx + b}{cx - a}$

*Tips: Tukar posisi $a$ dan $d$, lalu ubah tanda positif/negatifnya!

3. Invers Fungsi Kuadrat Sederhana:

Jika $f(x) = x^2 - c \quad (x \geq 0)$, maka pembalikannya:

$f^{-1}(x) = \sqrt{x + c}$

PEMBAHASAN LENGKAP SOSOK MATEMATIKA
LEVEL 1: INVERS LINEAR

Diketahui: $f(x) = 3x + 5$

Langkah 1 (Misalkan $y = f(x)$): $y = 3x + 5$

Langkah 2 (Pindahkan konstanta): $y - 5 = 3x \implies x = \frac{y - 5}{3}$

Maka: $f^{-1}(x) = \frac{x - 5}{3}$

Evaluasi $f^{-1}(14) = \frac{14 - 5}{3} = \frac{9}{3} = 3$

LEVEL 2: INVERS RASIONAL / PECAHAN

Diketahui: $g(x) = \frac{3x + 2}{x - 1}$

Menggunakan rumus cepat $\frac{ax+b}{cx+d} \implies \frac{-dx+b}{cx-a}$:

Dengan $a=3, b=2, c=1, d=-1$

Diperoleh: $g^{-1}(x) = \frac{-(-1)x + 2}{1x - 3} = \frac{x + 2}{x - 3}$

Evaluasi $g^{-1}(4) = \frac{4 + 2}{4 - 3} = \frac{6}{1} = 6$

LEVEL 3: INVERS KUADRAT

Diketahui: $h(x) = x^2 - 4 \quad (x \geq 0)$

Langkah 1: $y = x^2 - 4$

Langkah 2: $x^2 = y + 4 \implies x = \sqrt{y + 4}$

Maka: $h^{-1}(x) = \sqrt{x + 4}$

Evaluasi $h^{-1}(12) = \sqrt{12 + 4} = \sqrt{16} = 4$
